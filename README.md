# TVB Assistant

Discord bot with welcome messages, auto-role, tickets, moderation, and button roles.

## Render
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Instance: Free
- Environment variable: `DISCORD_TOKEN` = your bot token

Never commit your bot token to GitHub.

## Discord setup
Invite the bot with the `bot` and `applications.commands` scopes and permissions needed for moderation, roles, channel management, and messages.
